# Security Advisory

## Known Vulnerabilities in Dev Dependencies

This project uses Angular 19 which depends on versions of `tar` and `webpack` with known vulnerabilities. These affect only **development/build time** and do not impact production runtime.

### Affected Packages
- `tar` <=7.5.6 (transitive via pacote)
- `webpack` 5.49.0-5.104.0 (transitive via @angular-devkit/build-angular)

### Risk Assessment
- **Severity**: High/Medium
- **Attack Vector**: Local build environment only
- **Production Impact**: NonedevDependencies ( not deployed)

### Mitigation Options

1. **Update Angular to v21** (breaking change):
   ```bash
   npm install --prefix src/Validata.Web @angular/cli@latest @angular-devkit/build-angular@latest
   ```
   ⚠️ May break .NET 10 compatibility

2. **Use `npm audit --production`** to verify no production vulnerabilities:
   ```bash
   npm audit --prefix src/Validata.Web --omit=dev
   ```

3. **Accept risk** - vulnerabilities only in local build environment

### Recommendation
For local development, ensure:
- Only trusted users run `npm install`
- Build processes run in sandboxed environments
- Consider using `npm ci` instead of `npm install` for reproducible builds
